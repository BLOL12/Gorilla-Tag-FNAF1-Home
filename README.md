# Gorilla-Tag-FNAF1-Home
This is a FNAF1 home for Gorilla homes.
In order to use the mod, you will require Monkey mod manager and great mod menu or other mod menus that disable wind. And you will need Gorilla homes. Sorry I only know how to instal this on the Steam verion of Gorrila Tag. To instal, click on Steam, click on Gorilla tag, click Manage, click browse local files and then click BepinEx, then plugins then Gorrilahomes then home. Then drag the mod from your downloads into Homes.
